# 主題課程 02 範例程式碼  
這邊是**主題課程 02：在 Discord 與 AI 機器人聊天**的範例程式

## 檔案結構  
```sh
02_在 Discord 跟 AI 機器人聊天
├── /example                     範例程式碼
│  └── ...
├── /practice                    練習用程式碼
│  └── ...
├── /answer                      練習的答案
│  └── ...
├── remember.txt                 拿來暫時存放 discord token 與 google api key 的地方
├── 主題課程二教學簡報.pdf         上課用的簡報
└── README.md

```  

## 使用方法  
1. 點開 `主題課程二教學簡報.pdf` 觀看課程  
2. 點開 `/example` 隨著簡報進度做範例  
3. 點開 `/practice` 進行練習
4. 點開 `/answer` 查看自己做對了沒有
